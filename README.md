# BuildLens 🔍

**C++ 编译性能观测工具**

BuildLens 可以解析 Clang 的 `-ftime-trace` 输出，帮你精确找出拖慢 C++ 构建的原因——无论是哪个文件、哪个模板还是哪个头文件。

> 直观查看到底是什么在消耗你的构建时间。

------

## 🚧 状态

**v0.1 — MVP 开发中**

------

## 🎯 MVP 目标

- 解析 Clang 的 `-ftime-trace` JSON 输出
- 在可排序表格中显示最慢的编译单元
- 支持按文件名搜索和过滤

------

## ⚡ 快速开始

（即将提供详细指南）

```bash
# 使用 CMake 构建项目
cmake -B build
cmake --build build

# 运行 BuildLens
./build-lens /path/to/build/dir
```

**示例输出（v0.1 MVP）**：

| 排名 | 文件名  | 编译时间 (ms) | 模板实例数量 |
| ---- | ------- | ------------- | ------------ |
| 1    | Foo.cpp | 1250          | 12           |
| 2    | Bar.cpp | 980           | 8            |
| 3    | Baz.cpp | 870           | 5            |

> 点击表头即可排序，方便快速定位最耗时的文件。
