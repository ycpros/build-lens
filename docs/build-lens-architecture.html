核心数据层Core

TraceParser::ParseDirectory

校验目录存在性，枚举 JSON，逐个调用 ParseFile。

TraceParser::ParseFile

读取文件、解析 QJsonDocument，失败时返回耗时为 0 的记录。

ExtractTotalDuration

当前实现匹配 ph=="X" 且 name=="ExecuteCompiler"，微秒转毫秒。

InferSourceName

从 JSON 文件名去掉末尾 .json，得到展示用源文件名。

TraceRecord

承载 filename、total_duration_ms、source_path。

模型适配层Model

TraceTableModel

继承 QAbstractTableModel，把 std::vector<TraceRecord> 适配为三列表格。

SetRecords

重置模型数据，并默认按耗时数值降序排列。

data/headerData

提供展示文本、表头名称和耗时列右对齐；耗时显示为 ms 或 s。

QSortFilterProxyModel

界面层创建代理模型，用于文件名过滤和表头交互排序。

界面层UI

main.cpp

初始化 QApplication，设置应用元信息，创建并显示 MainWindow。

MainWindow

管理菜单、过滤框、表格、状态栏，以及加载目录的用户操作。

QLineEdit

文本变化后调用 setFilterFixedString，按文件名忽略大小写过滤。

QTableView

展示代理模型，启用表头排序、隔行颜色、单行选择和列宽自适应。

QStatusBar

基于过滤后的可见行计算文件数、总耗时和平均耗时。

关键调用链

用户操作触发后，数据如何从文件系统走到表格。

1

打开目录

文件(&F) → 打开目录… 或 Ctrl+O 触发 OnOpenDirectory，拿到目录路径后进入 LoadDirectory。

2

解析 JSON

TraceParser::ParseDirectory 枚举当前目录 JSON，ParseFile 读取 traceEvents 并过滤耗时大于 0 的记录。

3

刷新模型

TraceTableModel::SetRecords 替换记录列表，默认按耗时降序排序，然后 QTableView 调整列宽。

4

交互展示

搜索框更新代理模型过滤条件；状态栏遍历可见行并映射回源模型计算统计信息。

源码映射

每个文件在架构中的职责边界。

文件 职责 关键 API / 类型 架构备注
CMakeLists.txt 配置项目、Qt 依赖、目标源文件和 Clang trace 开关。 find_package(Qt5 5.15.2 EXACT)、CMAKE_AUTOMOC Qt 路径当前写在仓库配置里，换机器时需要调整或改成外部传参。
src/main.cpp 应用启动入口。 QApplication、MainWindow 只负责启动和元信息，不承载业务逻辑。
src/core/TraceRecord.h 定义单条编译记录。 TraceRecord source_path 当前保存 JSON 文件路径，不是真实源文件绝对路径。
src/core/TraceParser.h / .cpp 扫描目录、读取 JSON、提取总耗时。 ParseDirectory、ParseFile、ExtractTotalDuration 解析失败不会抛异常；返回 0 耗时记录后在目录层过滤掉。
src/model/TraceTableModel.h / .cpp 把记录集合适配为 Qt Model/View 表格。 QAbstractTableModel、sort、data 模型内置耗时数值排序，但代理模型交互排序还依赖展示数据。
src/ui/MainWindow.h / .cpp 组装菜单、过滤框、表格和状态栏。 OnOpenDirectory、LoadDirectory、UpdateStatusBar 当前实现没有目录拖放和双击打开文件逻辑。

实现要点

把代码里容易被图省略的细节显式写出来。

数据生命周期

  • 目录不存在时返回空记录列表。
  • 文件打不开或 JSON 解析失败时得到 0 耗时记录。
  • ParseDirectory 只保留 total_duration_ms > 0 的记录。

表格展示规则

  • 三列顺序固定为文件名、耗时、源路径。
  • 小于 1000 ms 显示为整数 ms，否则显示一位小数秒。
  • 耗时列右对齐，表格隐藏垂直表头。

界面交互边界

  • 打开目录通过系统目录选择器完成。
  • 过滤只针对文件名列，且忽略大小写。
  • 状态栏统计的是过滤后的可见记录，不是全量记录。

当前实现观察

这些不是文档错误，而是从源码读出的后续优化点。

JSON 事件名兼容性

  • 代码匹配 ExecuteCompiler，但 resources/sample 使用 Total 事件；样例可能无法被当前解析器加载。

目录扫描范围

  • 当前只扫描所选目录第一层，不递归构建输出子目录。

交互排序语义

  • 初始排序是数值排序；表头排序经代理模型时，耗时列可能按展示字符串比较。

已移除虚构能力

  • 原架构页提到目录拖放等能力，但源码尚未实现；本页已按实际代码修正。
