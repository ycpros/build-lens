### 竞品详情

| 竞品 | 类型 | 优势 | 劣势 |
|------|------|------|------|
| **ClangBuildAnalyzer** | 开源 CLI | 社区认可，WebKit/LLVM 团队在用 | 纯 CLI，无历史追踪，无 UI |
| **compile-time-perf** | 开源 CLI | 支持内存指标 | 实验性质，用户极少 |
| **Incredibuild** | 商业 SaaS | 分布式加速，企业级 | 做加速不做分析，价格贵 |
| **BuildAnalyzer** | 商业桌面 | Windows GUI | 仅 Windows，功能简单，无 CI |
| **Datadog C++ tracing** | 通用 APM | 有 C++ SDK | 通用 APM，不专注构建 |
| **CodSpeed** | SaaS | CI 性能回归检测 | 专注运行时性能，非编译时 |

### 🔑 核心发现

**CI/CD 构建性能监控 SaaS —— 目前没有竞品。** 这是一个蓝海。

现有工具的共性缺陷：
- 全是手动、单次分析（你跑一次看一次）
- 没有跨时间追踪（不知道什么时候变慢的）
- 没有 CI 集成（不会自动跑、自动报警）
- 没有团队协作（不能共享、不能对比）

## 路径 A：打磨桌面工具 → 一次性/订阅售卖

**产品形态**：Windows/macOS/Linux 桌面应用
**目标用户**：个人 C++ 开发者
**核心功能**：
- 火焰图、树形图可视化编译耗时
- 头文件包含链分析（哪个 include 最贵）
- 模板实例化耗时拆解
- 与 IDE 集成（VS Code / CLion 插件）

**定价参考**：
- 个人版：$49-99 一次性 / $5-10/月
- 团队版：$299/年/5 seats

**收入天花板**：$50K-200K/年
**优点**：开发周期短，你一个人能做
**缺点**：用户基数有限，增长慢

---

## 路径 B：CI/CD 构建监控平台 (SaaS) ⭐ 推荐

**产品形态**：Web 平台 + CLI 工具
**目标用户**：C++ 团队（游戏、金融、嵌入式、浏览器、数据库…）
**核心功能**：
- CI 中自动收集 -ftime-trace 数据，上传到云端
- 构建时间趋势图、回归检测（某次 commit 突然变慢）
- 跨分支对比（feature 分支比 main 慢多少？）
- 团队看板：谁提交的代码在拖慢构建？
- 智能建议：哪个头文件值得做预编译/precompiled header

**定价参考**（参考 Sentry / Datadog 模式）：
- Free tier：1 个项目，7 天数据保留
- Team：$29/月/seat，无限项目，90 天数据
- Enterprise：$custom，SSO、on-prem、SLA

**收入天花板**：$500K-5M/年（取决于获客）
**优点**：经常性收入、数据护城河、企业有预算
**缺点**：前期开发量大，需要 infra

**参考案例**：
- **Sentry** — 从开源 Django 插件做到 $100M+ ARR
- **Codecov** — 代码覆盖率 SaaS，被 Sentry 收购
- **BuildPulse** — 专注于测试 flakes 的 SaaS，小团队，已盈利

## 路径 C：开源引流 → 企业定制/咨询

**产品形态**：开源桌面工具 + GitHub stars → 接企业定制
**收入模式**：咨询费 $150-300/小时
**典型客户**：游戏公司优化 UE 编译、芯片公司优化驱动编译
**收入天花板**：$100K-300K/年（但不可扩展，用时间换钱）
**优点**：立刻可以开始
**缺点**：本质是卖时间，不是做产品

## 建议路线图

### 阶段 1（1-2 周）：把产品做"能用"
- ✅ 修复示例数据格式：改为真实 Clang 格式（`ph: "X"` + `name: "ExecuteCompiler"`）
- ✅ 用真实 Clang 项目验证能跑通（比如编译 LLVM 某个子项目）
- ✅ 增加火焰图/chart 可视化
- ✅ 加头文件包含耗时分析

### 阶段 2（1-2 月）：从桌面到 Web
- CLI 工具：`buildlens analyze ./build-dir/` 输出 HTML 报告
- 静态 HTML 报告可直接分享给同事
- 发布到 GitHub，收集反馈

### 阶段 3（3-6 月）：SaaS MVP
- CI 集成（GitHub Actions / GitLab CI）
- 数据上传 + Web dashboard
- 开始收费

### 关键验证点（现在就该做）
- 去 Reddit r/cpp、Hacker News 发帖："如果有个工具能追踪 CI 中每次构建的编译耗时变化，你会付费吗？"
- 找 5 个 C++ 团队聊他们的构建痛点
